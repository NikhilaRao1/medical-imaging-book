# Tentative Edits Guide

This branch is for proposed changes to the textbook. Do **not** edit the `main` branch directly.

## Instructions for Contributors

1. Make all edits in this branch (`tentative-edits`) only.
2. Chapters are located in `chapter1.md` and `chapter2.md`.
3. Add images to the `/images` folder. Cite sources clearly if not generated internally.
4. Commit your changes with a clear message:
   - Example: "Update Chapter 2.12: add control systems diagram"
5. Submit a Pull Request (PR) from this branch to `main` when ready for review.
